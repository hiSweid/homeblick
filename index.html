Homeblick

A fluid, glassy wall-display for Home Assistant. Tiles, faces, weather, energy and voice, built for a square tablet on the wall.

What it is

A web UI with configurable faces (grid, music, clock, weather, calendar, energy, timer, doorbell camera) that runs as a Home Assistant panel or on a kiosk device. Spring, FLIP and press animations throughout.

Planned

  • HACS custom integration with config flow, no add-on and no token needed
  • Settings stored in Home Assistant, shared between all displays
  • evcc energy data via the existing evcc integration

Status

Early prototype. Not yet installable.
